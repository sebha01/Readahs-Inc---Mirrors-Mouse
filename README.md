# Readahs-Inc---Mirrors-Mouse
Mirror's Mouse is a first-person parkour game inspired by Mirror's Edge using Unity 6.3 LTS. Players control a mouse escaping a suburban house while rescuing colony members, mastering movement abilities and traversing household environments.
